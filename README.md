\# Student Management System



\## Project Objective



The Student Management System is a responsive web application developed as the final project of my web development internship. The main objective of the project is to apply the HTML, CSS and JavaScript concepts learned during the internship to a practical application. The system allows student information to be added, updated, searched and managed through a simple interface.



\## Project Overview



The application provides a dashboard containing basic student statistics and a student record section. Users can enter a student's name, roll number, course and marks. The application validates the entered information before saving it. Each student record displays the calculated grade and pass/fail status.

\## Main Features



\* Add new student records

\* Edit existing student records

\* Delete student records

\* Search students by name or roll number

\* Filter students by course

\* Sort records by name or marks

\* Form validation

\* Automatic grade calculation

\* Pass/fail calculation

\* Dynamic student statistics

\* Local storage for saving records

\* Responsive layout for desktop, tablet and mobile devices



\## JavaScript Concepts



The project uses variables, constants, arrays, objects, functions, conditional statements, loops and array methods. DOM manipulation is used to update the table and statistics dynamically. Event listeners are used for form submission, searching, filtering, sorting and button interactions. Local Storage is used so that student records are not lost when the page is refreshed.



\## Challenges Faced



One challenge was managing the student records while allowing users to add, edit and delete data without refreshing the page. Another challenge was combining search, filtering and sorting without changing the original data incorrectly. Making the interface usable on smaller screens was also a challenge.



\## Solutions Implemented



Separate functions were created for validation, rendering records, calculating grades, updating statistics and applying filters. The table is dynamically generated whenever the student data changes. CSS media queries were added to adjust the layout for tablets and mobile devices. Local Storage was also added to keep the records available after refreshing the browser.



\## Key Learnings



This project helped me understand how different web development concepts work together in one application. I gained more practical experience with DOM manipulation, events, arrays, objects, functions, form validation and responsive CSS. I also learned the basic Git and GitHub workflow required for maintaining and deploying a project.



\## Future Improvements



The project can be improved by adding student attendance, login functionality, separate student profile pages, better data visualisation and a backend database for storing records permanently.
